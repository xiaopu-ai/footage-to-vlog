# 人物见证访谈（testimonial）

> 样片：一条客户项目的人物访谈片（定版 v7），3:52，89 镜、109 条字幕、13 个音效、3 段配乐，2026-11-10 定版。对标客户人工剪的成片（2:12）。
> 一句话：一个玩家坐着讲，品牌方关心的每个问题都是卖点；回答说到什么，画面和包装就出什么。

## 适用素材

- 一段或几段清楚的采访，人声干净，单机位也能做。
- 跟回答内容对得上的 B-roll：本人骑行、产品细节、活动现场。
- 品牌方的问题清单：每个问题都是卖点，尽量都体现。还有官方口号和 Logo。

## 结构（3–4 分钟）

| 段落 | 时长 | 做法 |
|---|---|---|
| 冷开场 | 0–2 s | 毛笔字倒计时「3 / 2 / 1 / 走！」拍在画面中央，每一下落在拍点上（118 BPM 时是第 16 / 31 / 46 帧，「走！」在 54 帧半拍）；画面每拍推近一档，加衰减震动（`slam`） |
| 钩子 | 2–7 s | 鼓点进：大字口号镂空透出画面再穿进去，或三联竖屏按拍滑入合成一屏；接一句最有劲的金句 |
| 人物卡 | 约 7–10 s | 定格人物，出人名条（`lower`） |
| 问答章节 × N | 每章 20–45 s | 问题卡（`qcard`）→ 回答。回答用采访硬切，每个剪气口在全景 / 近景之间交替；说到具体东西时盖 layer 1 的 B-roll 或出信息卡，用 `say` 触发 |
| 纯音乐段 | 5–10 s | 只能放在没人说话的地方：产品性能蒙太奇，可以用冲击推（`punch`），转场可以花一点 |
| 收尾 | 10–15 s | 人物或群体喊口号的原声 → 官方口号字（`lockup` 或 `brushword`）→ Logo |

章节的顺序按品牌方的问题来，每章开头的问题卡至少停 110 帧（≈3.7 s），观众要读得完。

## 镜头和转场

- 🔴 **说话中一律硬切**（`cut`）。只在问题卡出现时用 12 帧蒙版擦入（`wipe`）+ 一声 whoosh，入镜画面轻推。v5 说话中轮换水波、开孔、推屏，用户说「跳戏」「像 bug」，全撤了。
- 采访镜头统一用 `move: "interview"`：
  - 同一段连续采访缓推不复位；
  - 剪气口处在全景 1.03 和近景 1.18 之间交替；
  - 短于 15 帧的碎片沿用上一档。
- 单机位 1080p 推近不超过约 1.2 倍，再大会软。
- 有信息卡时用 `make_room: "right"`，人往左让，**字卡不挡脸**。
- B-roll 必须和说的话对得上。说越野摩托就不能配水上摩托：素材里没有就用人 + 信息卡 / 时间线图讲。
- 白闪、闪黑、说话中的大幅转场都不用。

## 文字包装

| 元素 | type | 要点 |
|---|---|---|
| 倒计时 / 开场大字 | `slam` | 毛笔字（模板默认马善政，访谈示例片原样），2 帧内 2.6→1 倍，震动 10 帧；渲 1:1 静帧量字形中心，用 `nudge` 修到 ≤ 2 px |
| 问题卡 | `qcard` | 序号 + 2–3 行题目，关键词用 `hi` 高亮，品牌 Logo 小角标；不要多余的装饰线（v6 那根橙色细线被要求删掉） |
| 关键词 | `brushword` | 说到核心词时出，一屏一个，避开人脸 |
| 人名条 | `lower` | 开场一次 |
| 信息卡 | `spec` / `image` | 型号、权益、时间线；按 `say` 触发，说到哪出到哪 |
| 字幕 | `captions` | 思源黑体 46 px，底部 90 px；每条不超过 17 字，只在词边界断 |
| 收尾 | `lockup` | 官方口号原样（照物料原文逐字核对，形近字比如「境 / 镜」也不能写错） |

## 声音

- **配乐**：`assets/music-plans/testimonial.plan.json`（118 BPM：倒计时蓄力 → 开场 drop → 留出人声空间的轻律动 → 小 build → 产品段 → 收尾）。
  - 只在乐句边界拼接，结尾自然落在片尾。
  - 人声出现时按逐字区间自动压低约 13 dB（`duck`）。
- **音效 10–15 个**，只放在：
  - 倒计时每一下（生成的重拍，「材质 + 动作 + 结果」式提示词）；
  - 人物卡定格；
  - 每个问题卡（whoosh）；
  - 纯音乐段入口；
  - 片尾 Logo。

  不用 tick / snap / pop 这类短促尖锐的声音。v5 配了约 70 个，用户说「画蛇添足」。
- **交付**：成片 −14 LUFS，外加纯人声版（同画面只留人声，约 −16 LUFS）和卡点表。

## 合规（这类片子最容易踩）

- 删掉绝对化用语：世界第一、无可匹敌、没有竞品、国内第一、最残酷。删完**一定检查前后句是否说完整**。Q3 曾停在「来说」，后来接回原片「就是这个」+ 竖大拇指才补上。
- 删掉贬低别家的话：「别的品牌做不到」。

```json
{
  "style": "testimonial",
  "duration": "auto",
  "shots": [
    { "id": "OPEN1", "src": "broll/C0101.MP4", "in": 3.3, "at": 0, "dur": 60, "move": "push" },
    { "id": "IV001", "src": "interview/A001_C003.MP4", "in": 182.4, "dur": 96, "move": "interview", "audio": true },
    { "id": "BR001", "layer": 1, "src": "broll/C0102.MP4", "in": 4.5, "at": { "say": "入坑" }, "dur": { "s": 2.5 } }
  ],
  "texts": [
    { "type": "slam", "text": "3", "at": 16, "dur": 15 },
    { "type": "qcard", "no": 1, "lines": ["从第一台车", "到全系玩家", "是怎么「入坑」的？"], "hi": "「入坑」", "at": 607, "dur": 115 },
    { "type": "brushword", "text": "大满贯", "at": { "say": "大满贯" }, "dur": 50, "x": 1400, "y": 460 }
  ],
  "captions": { "enabled": true, "max": 17 },
  "audio": {
    "music": { "src": "audio/music.wav", "gain": 0.8, "duck": { "under": "voice", "db": -13 } },
    "sfx": [ { "src": "audio/sfx/slam_v1.wav", "at": 18, "gain": 0.7 } ]
  }
}
```

interview 镜头一般不手写：用 `paper_edit.py` 生成后粘进来，再往上盖 layer 1 的 B-roll。
