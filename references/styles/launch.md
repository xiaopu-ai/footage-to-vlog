# 产品发布大片（launch）

> 样片：一条客户项目的新品发布片（定版 v2），33.7 s、33 镜、128 BPM，2026-11-11 定版。对标 Ducati「World Première · Desmo450 MX」（拆解要点见下）。
> 一句话：无口播，音乐 + 产品细节 + 光 + 大字参数；开头第 0 秒就要有冲击，每一刀都在拍上。

## 适用素材

- 产品静态摆拍或滑轨慢移镜头：字标、材质、部件、整机侧面。
- 几条动态镜头：航拍、骑行，Drop 段要用。
- 官方参数表 PDF：**每个数字都要对官方原文**。

## 结构（约 34 s，128 BPM，一拍 = 14.06 帧，j = 第几拍）

| 段落 | 拍 | 时间 | 做法 |
|---|---|---|---|
| 冷开场重击 | j0–16 | 0–7.5 s | 9 个细节镜，2 拍一切，最后 4 镜 1 拍一切加速；第 0 帧就是重击 |
| 镲片 / 揭示 | j16–24 | 7.5–11.3 s | 光带扫出产品字标（`reveal` + `sweep`） |
| 蓄力 | j24–32 | 11.3–15.0 s | 艇队 / 码头，1 拍一切 |
| Drop | j32–40 | 15.0–18.8 s | 3 条航拍 + 1 条骑行 |
| 参数五连 | j40–60 | 18.8–28.1 s | 每张参数卡（`spec`）停 4 拍；第 3 拍换背景角度，字不动 |
| 字标高潮 | j60–64 | 28.1–30.0 s | 产品名大字 |
| 收尾 | j64– | 30.0–33.7 s | 整艇压暗 → j66 出官方 Logo |

v1 是 46 s、17 镜、前 15 秒只有 4 个镜头，第一下重击在 7.2 s。用户说「节奏偏慢，尤其开头特别平」，定版后被推翻重做。**开头 3 秒内没有重击、前 10 秒没有鼓的配乐不用。**

## 镜头和转场

- 镜头按拍网格排（`{"beat": j}`），**关键的刀落在重音上**：开场第一刀、镲片揭示、Drop 第一刀、字标高潮写 `{"accent": n}`，其余加 `"snap": "accent"`。重音表来自 `tempo.py`（见 `references/music-sfx.md`）。
- 成片用 `render.py` 出（音轨不会偏），再用 `qa.py` 量卡点：画面领先音频 0–2 帧（`lead_frames > 0` 表示画面先到）。示例片 v2 当时用 Remotion 直出，画面晚了约 1 帧，整体提前 2 帧后中位领先 0.9 帧。现在先排除封装延迟，再决定要不要平移。
- 转场只在拍点上用，分工固定：
  - `sweep`（10 帧）：揭示、换参数。暖光带走过，后面露出下一镜，光带在拍点那一帧走完。
  - `punch`（8 帧）：开场、Drop、重音、高潮。上一镜最后几帧加速推进 + 拖影，下一镜从 1.15 回落，同时提亮 16%。
  - 其余一律 `cut`。
- 光要像真光，不能是一根线（用户原话：「就是一根白色的线……不像太阳光照射在上面」）。模板的 `sweep` / `reveal` 已经是三层光：宽软补光带半宽约 45%、只亮最亮 30% 的高光带、7% 暖色空气光，ease-in-out。
- 底子要比光带暗，但别整体压太暗：v2 用户嫌开头太暗，提亮约 25% 后光带照样明显。

## 文字包装

- `spec`：大数字 D-DIN Condensed + 单位 + 一行说明，左上角压暗衬底。例：`170` `HP` 发动机马力。不写「最强」这类词。
- `reveal`：产品名或字标用光带扫出，不用细光线（Streak）扫字。
- 收尾：官方 Logo（`image` 或 `endcard`），不重绘。
- 全片除了参数卡和字标，不加别的字。

## 调色

- 风格帧给 3 套：A 暗场一束光、B 阴天 2.35:1、C 黑金。示例片选了 C：暗部干净、高光暖金，品牌色单独保留。
- 品牌强调色可以用单色遮罩只留一种颜色（金色：alpha = 4·(R−B) − 0.35），其余降饱和。

## 声音

- **配乐**：`assets/music-plans/launch.plan.json`。
  - 计划要写明：第 0 秒重击、不要铺垫、鼓从头到尾不停；固定 BPM、不要 half-time。
  - 每段按整小节写，128 BPM 时 3750 ms = 2 小节。每段至少 3000 ms，否则接口报 422。
  - 出 2–3 首给用户选。用 `trim_s` 剪掉开头，让第一下重击落在第 0 帧。
- **音效**：这条没用，音乐撑满。要加的话只挂揭示和 Logo。
- **交付**：成片 + 无声版 + 卡点表，−14 LUFS / −1.5 dBTP。

## 对标拆解要点（Ducati Desmo450 MX）

- 先拍抽象局部，再到产品全貌（从抽象到身份），131 BPM，结构点卡在重击上。
- 阴天平光调色，字标卡几乎不做动画。
- 原片没有参数大字：参数五连是我们加的，用户认可。
