# 平台合规和品牌规范

国内短视频平台（抖音等）判「画面违规」只看结果，素材是官方给的也算。下面这些在分镜阶段就要查，交付前再扫一遍。

## 画面

- 🚫 **二维码**：官方实拍里自带的也算（站外引流）。有一条片子因为画面里的二维码被判违规、限制自己可见。交付前跑 `python3 scripts/qr_scan.py <成片> <封面…>`，退出码 1 = 还有能扫的码。
- 🚫 **电话号码**：假号也算。
- 🚫 **地图 / 地球仪**：有「问题地图」风险。
- 🚫 **第三方商标和品牌**：手表、仪表上的品牌标、饮料罐、别家车标。换镜、换时间段，或用 `frame.scale` 裁掉。
- 🚫 **车牌、船号、参赛号**：比如船身上的号码。
- 🚫 **误导性画面**：口播说 A 产品，画面配 B 产品。素材里没有就用人 + 信息卡讲。
- 有的东西实在去不掉，就打码或贴块覆盖，打码要跟踪物体运动。

## 口播和文字

- 🚫 **绝对化 / 承诺词**：最、第一、唯一、无可匹敌、没有竞品、国内第一、世界第一、永久、包、稳赚；也不写「让你 / 帮你提效、省钱 XX%」这种第二人称收益承诺。
- 🚫 **贬低别家**：「别的品牌做不到」。
- 🚫 **站外导流和安装引导**：网址、「搜索 XX」、「加微信」、下载按钮。
- 涉及数字和效果的说法一律挂来源：「官方参数」「厂商介绍里说」。参数逐条对官方参数表（PDF / 官网），不凭印象写。
- 删句以后检查前后句是否说完整，见 `interview-edit.md`。

## 品牌规范

- **Logo**：从品牌官网或客户给的文件取，SVG 优先；不重绘、不改色（白 / 黑两版按底色选）。
- **口号和产品名**：照官方原文，一个字都不改。例：物料上印的是「境」，就不能写成形近的「镜」。
- **字体**：只用免费可商用的，来源和授权写进 `public/fonts/LICENSES.md`。不装进系统字体册，项目里用 FontFace 加载。
- **在世人物的照片**：不做灰度 / 黑白处理，有悼念含义。
