# 检查清单

## 渲前清单（整片渲染前逐条过，有一条不过就不渲）

- [ ] `timeline.py` lint 零错误，警告逐条看过。
- [ ] `public/clips/clips.json` 里全部是 final 质量，没有 draft 和占位素材。
- [ ] 每镜首、中、尾抽帧看过：
  - 没有商标、车牌 / 船号、第三方品牌、二维码、电话、地图 / 地球仪；
  - 画面和说的话对得上；
  - 字卡不挡脸。
- [ ] 采访说话中全部是硬切。
- [ ] 字：
  - 毛笔字清楚；
  - 居中元素量过像素，误差 ≤ 2 px；
  - 同组并列卡片行数和尺寸一致。
- [ ] 字幕没拆词，每条不超过 17 字，没有单独的语气词。
- [ ] 合规删句后，前后句都说完整了。
- [ ] 参数逐条对过官方参数表；口号和 Logo 用的是官方写法 / 官方文件。
- [ ] 卡点类：所有段落切换落在小节头，切点在网格上（lint 没报偏差）。
- [ ] 慢放没有低于原生帧率。
- [ ] 音效数量在风格范围内，没有短促尖锐、跟画面无关的声音。
- [ ] `npx tsc --noEmit` 干净。

## 渲后检查（交付前全部要过）

```bash
python3 scripts/sheet.py --video out/raw.mp4 --fps 2 --out work/qa/sheet.jpg   # 看整片联系表
python3 scripts/synccheck.py out/raw.mp4 <proj>                                  # 卡点 + 黑场
python3 scripts/jitter_scan.py out/raw.mp4                                       # 来回抖动（没有输出 = 干净）
```

| 检查 | 通过标准 |
|---|---|
| 联系表 | 没有黑帧、白闪、穿帮、错位；颜色同段一致 |
| 卡点（卡点类风格） | 「音频起音 − 画面切点」中位数在 −2 ~ 0 帧（画面领先），|差| ≤ 1.5 帧的比例 ≥ 85%；不达标就在 `edit.json` 里整体平移后重渲 |
| 黑场 | 除了设计的 `dip`，没有意外黑场 |
| 抖动 | 没有「第 i 帧和 i+1 帧不同、和 i+2 帧几乎相同」的来回跳 |
| 响度 | −14 LUFS ±0.5，真峰值 ≤ −1.5 dBTP（先 `alimiter=limit=0.74`，再 `loudnorm.py`） |
| 二维码 | `python3 scripts/qr_scan.py out/final.mp4` 退出码 0 |
| 亲眼看 | 至少把开场、每个段落切换、落版各看一遍；没看过不说「完成」 |

## 交付物

- `out/<片名>-v<N>.mp4`：成片，1920×1080、30 fps、H.264、AAC、−14 LUFS。
- 纯人声版（采访类）或无声版（纯音乐类）：`ffmpeg -i final.mp4 -an -c:v copy 无声版.mp4`。
- `out/<片名>-v<N>-卡点表.md`（`cuesheet.py`）。
- `HANDOFF.md`：定版说明、关键参数、用户意见和对应改动、已知不足。

`out/` 只留最近两版，旧版直接删。
