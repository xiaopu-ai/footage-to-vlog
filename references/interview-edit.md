# 采访剪辑：转写 → 纸面剪辑 → 字幕

不用剪辑软件，「按文字剪」靠逐字时间码完成。

## 1. 转写

```bash
set -a && . ./.env && set +a   # 只加载，不打印 key
python3 scripts/transcribe.py <采访文件…> --out work/transcripts --keyterms "品牌名,子品牌,型号,口号" --lang zh
```

- 产物：
  - `.scribe.json`：ElevenLabs Scribe v2 原始结果，逐字时间；
  - `.sentences.md`：逐句文稿，带起止秒和帧，末尾附停顿清单；
  - `.srt`。
- 已有 `.scribe.json` 时直接复用，不重复扣费。
- 专有名词、口号、型号放进 `--keyterms`。ASR 常见错字：
  - 口号里的字被听成同音、近音字
  - 品牌名被听成同音字
  - 「艇」→「挺」
  - 「它」→「他」
  - 「搞得」→「搞的」
  
  这类错字后面用 `--fix` 修。

## 2. 纸面剪辑

1. 读一遍全部 `.sentences.md`，按品牌方的问题清单（或 PLAN.md 的章节）挑回答。
2. 每段抄起止秒，写进 `work/paper_edit.json`：

```json
[
  { "src": "interview/A001_C003.MP4", "from_s": 182.4, "to_s": 196.2, "note": "Q1 入坑：因伤入坑" },
  { "src": "interview/A001_C003.MP4", "from_s": 201.0, "to_s": 214.8, "note": "Q1 接：第一台是越野车" }
]
```

3. 生成 interview 镜头和成片逐字时间：

```bash
python3 scripts/paper_edit.py <proj> --fix "在坐=在座,以经=已经"
```

   - 选段边界会自动吸附到词间停顿，不切字。
   - 镜头数组写在 `work/paper_edit.shots.json`，粘进 `edit.json` 的 `shots`。
   - 同时写出 `words.json`，`{"say": …}` 和字幕都靠它。
   - 也可以按句号选段：`--from-sentences "interview/xxx.MP4:10,11,15"`；采访从成片第几帧开始用 `--at 60` 指定。
   - ⚠️ 转写必须从素材第 0 秒开始（`paper_edit.py` 没有偏移参数）。只想转一部分，就转「从 0 到某秒」，不要截中间一段。

4. 往上盖 B-roll（layer 1）、问题卡、信息卡，按 `{"say": "…"}` 对齐。说到哪出到哪。

### 选段原则

- 每个问题都是卖点，尽量都留，但每章只留最有信息量、最口语生动的几句。
- 开场金句挑一句最有劲的放在人物卡前。
- 🔴 **合规删句后检查前后句是否说完整**。`paper_edit.py` 发现选段停在「来说」「就是」「然后」这类没说完的词上会警告。访谈示例片第 3 题删掉「世界第一，无可匹敌，没有竞品」后停在「来说」，被用户指出「话没说完就进动效」。后来接上原片后面的「就是这个」+ 竖大拇指才补上。
- 删掉：绝对化用语、贬低别的品牌、玩笑里的不当话（比如「年少不玩 XX，明天结婚后天离」）。

## 3. 字幕

`captions.enabled: true` 时，`timeline.py` 编译时自动调 `captions.py` 生成字幕。

规则（用户审过）：
- 先按标点和停顿断。
- 超过 17 字的，只在 jieba 词边界和 ASR 词元边界上拆：
  - 尽量从中间拆；
  - 优先拆在「的 / 了 / 呢 / 啊 / 吧 / 嘛 / 呀」之后，或「因为 / 但是 / 然后 / 直接 / 所以」之前；
  - 两边各不少于 4 字。
- 单独的语气词（呃、嗯、哎、啊、哦）不出字幕。
- 去掉句末标点，相邻字幕不重叠。

专有名词加进词典（`work/dict.txt`，一行一个），否则「钓鱼艇」「活水箱」可能被拆开。访谈示例片 v6 的「钓鱼」「马力」「维修」都被拆成过两条。

## 4. 采访画面

- `move: "interview"`：同段缓推不复位；剪气口处全景 1.03 / 近景 1.18 交替，像两台机位；短于 15 帧的碎片沿用上一档。
- 单机位 1080p 推近不超过约 1.2 倍。
- 信息卡出现时 `make_room: "right"`，人左移让位，**字卡不挡脸**。
- 说话中一律硬切。
