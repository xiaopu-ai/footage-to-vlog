# 规则分级

skill 里的规则分四级。级别不同，处理方式不同：前两级必须遵守，后两级可以偏离，但要写清理由。

| 级别 | 含义 | 违反了怎么办 |
|---|---|---|
| **A 用户硬要求** | 用户（或品牌方）明确说过、审片时否过的 | 不能违反。确实要变，先问用户 |
| **B 技术约束** | 违反会出错、出事故，或被平台判违规 | 不能违反。工具会报错（lint / qa 非零退出） |
| **C 风格建议** | 经验上好看、被审过的做法 | 可以偏离，但要在 `work/PLAN.md` 或 `note` 里写理由，审核时告诉用户 |
| **D 示例参数** | 示例片里的具体数字，比如 46 秒、124 BPM、第 120 帧换字 | 参考用，按本片情况定 |

## A 用户硬要求

- 每个审核节点停下来等用户确认（节点表见 `review.md`），不一口气做到整片。
- 采访说话中一律硬切；只在问题卡、章节卡出现时用小转场。
- 画面不说谎：口播说 A，画面不配 B。素材里没有的，用人加信息卡讲。
- 字卡和包装不挡人脸。
- 毛笔字清楚好认，不用程序飞白、抽象行草。
- 「冷峻」不等于「暗」：人脸和暗部不压死。
- 配乐不要慢前奏、平铺直叙、战争片式史诗；卡点类片子第一小节就要有冲击。
- 音效少而准，不用短促尖锐、和画面无关的 tick / pop。
- 官方物料原样用：Logo、口号、产品名一个字都不改。

## B 技术约束（工具会检查）

| 规则 | 谁检查 |
|---|---|
| 慢放不低于素材原生帧率（60p 最慢 0.5×，120p 最慢 0.25×） | `timeline.py` lint |
| 采访镜头开原声时不能变速 | `timeline.py` lint |
| 同一素材的源区间不能重叠复用 | `timeline.py` lint、`coverage.py --strict` |
| 燃剪的 drop 段至少有一处变速坡 | `timeline.py` lint |
| 燃剪 drop 段的硬切至少 60% 落在强重音 ±2 帧内 | `timeline.py` lint、`synccheck.py`、`qa.py` |
| 字幕不拆词，每条不超过 17 字 | `captions.py` |
| 整片渲染前片段全部是 final 质量 | `render.py` |
| 成片色彩：yuv420p、tv 范围、BT.709 三项标签齐全 | `qa.py` |
| 音画对齐：成片音轨和规范混音的时移 ≤ 5 ms | `qa.py`（`audio_sync.py`） |
| 响度 −14 LUFS ±0.5，真峰值 ≤ −1.5 dBTP | `qa.py` |
| 除了设计好的暗场（dip、黑场镜头、深底落版），没有意外黑场 | `qa.py`（`synccheck.py`） |
| 画面里没有能扫出来的二维码；没有电话、地图、第三方商标、车牌 / 船号 | `qa.py`（`qr_scan.py`）+ 人工核对镜头 |
| 绝对化用语、贬低别家、站外导流不进口播和字卡 | 人工核对，见 `compliance.md` |
| 全机同一时间只跑一个重任务 | `queue.sh` |

## C 风格建议（可以偏离，写理由）

- 燃剪 drop 段 2–3 处变速坡；连续恒速镜头不超过 4 个；平均镜长约 1.8 s，动作留满一小节；短于 1.5 s 的镜头别超过四成（个数）且三成（时长）。
- 切点吸附 8 分音符；小节头的刀放在当帧或前 1 帧；成片里画面领先音频 0–2 帧。
- 同一段、同类内容的镜头，亮度分位（p5 / p95）差不超过约 3 个百分点，冷暖（中间调 R−B）在同一区间。**这是告警，不是硬门槛**：构图本来就不同的镜头（大片水面 vs 带天空的合影）会超；超了就看连切对比图，有意的亮度变化写进 `note`。
- 不同素材数 / 镜头数 ≥ 0.7；同一条素材最多用 2 次。
- 访谈类音效 10–15 个，燃剪分层约 20 个，发布片和口号片 0–5 个。
- 每种风格的段落结构、剪辑密度、文字位置，见 `styles/*.md`。

## D 示例参数

风格手册里所有带具体数值的例子（时长、BPM、帧号、镜头数、坐标、调色参数）都属于这一级。新片子要按自己的音乐、素材和时长重新定。

## 怎么说「检查通过」

- 只说跑过的检查通过了，并写清覆盖范围。比如「二维码按 2 fps + 每镜首中尾扫了 312 帧，未解出内容」，而不是「没有二维码」。
- C 级规则的例外、没跑的检查、要人工看的项目，单独列出来。
- 「agent 看过静帧」「数值检查通过」「用户看过并批准」是三件不同的事，分开记（`state.py` 记录用户批准）。
- 用户定版说明用户接受了成片，不等于每条 C 级规则都满足了。
