# 素材能撑起哪些风格

先盘点素材（`inventory.py` + 镜头日志），再按下表判断。**给用户 2–3 个建议，每个都说清楚靠哪几类镜头撑起来、缺什么。**

## 本 skill 覆盖的四种（都有定版样片）

| 风格 | 需要的素材 | 不够时 |
|---|---|---|
| **人物见证访谈** `testimonial` | 一段清楚的采访（能用的回答 ≥ 3 分钟）+ 跟回答对得上的 B-roll + 品牌方的问题清单 | 缺 B-roll 的段落用人 + 信息卡讲，不配对不上的画面 |
| **产品发布大片** `launch` | 产品细节镜头（字标、材质、部件、整机侧面，滑轨慢移最好）+ 几条动态（航拍 / 骑行）+ 官方参数表 | 没有细节镜头就做不成；动态不够就缩短 Drop 段 |
| **红牛式卡点燃剪** `hype` | 有动作的镜头（甩尾、掠过、跳跃，高帧率更好）+ 低空航拍 + 人脸表情 + 现场原声 | 没有第一视角时，用对脸机位 + 长焦压缩 + 水花前景做「近」 |
| **品牌口号 / 宣言片** `manifesto` | 官方口号 2–4 句 + 大景（航拍、海岸）+ 群体时刻（挥手、并排、开扇）+ 可选的喊口号原声 | 没有官方口号就不做，**不替品牌编口号** |

同一批素材可以出好几种：示例项目那批 101 条，四种全做了，素材复用得很多。混搭的话，常见的是访谈 + 质感镜头、发布片接燃剪段落。

## 这批素材做不了的（要重拍，别硬做）

| 风格 | 缺什么 |
|---|---|
| 人物 / 赛事纪录片 | 跨时间段的跟拍、冲突和代价 |
| 特技动作片（Gymkhana 类） | 专门的车手和场地 |
| FPV 穿越追拍 | 穿越机素材 |
| 工程 / 设计幕后 | 工厂、研发、CAD 素材 |
| 产品讲解 / 测评走查 | 主持人围着车讲 |
| 电影感产品质感片 | 能做一部分，但缺打光和高帧率微距，高级感上限受限 |

另外，**苹果发布会式的软件产品片是另一种风格**（界面不离设备、禁快切），不归本 skill，也不要把它的规则套到实拍硬件片上。

## 判断顺序

1. 有没有能用的采访？有 → 访谈可做。
2. 有没有产品细节镜头？有 → 发布片可做。
3. 动作镜头够不够撑起 20 秒 drop？够 → 燃剪可做。
4. 有没有官方口号？有 → 口号片可做。
5. 把结论写进 `work/PLAN.md`，交给用户选。
